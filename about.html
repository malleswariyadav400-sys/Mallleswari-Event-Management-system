Welcome to Malleswari Event Management

Malleswari Event Management System is a simple and user-friendly web application designed to help users discover and register for different events.

Our system provides information about upcoming events, event dates, locations and other important details. Users can easily explore events and register for the events they are interested in.

This project is developed as a student project to demonstrate the use of HTML, CSS and JavaScript in developing a functional event management website.
